# Extended Surface Heat Transfer Analysis (TD1002c)

MATLAB implementation for analyzing temperature distribution across an extended surface module (TD1002c) under various power levels (2.0W to 10.0W).

## Overview
This project models heat transfer through a cylindrical brass rod using analytical solutions (hyperbolic cosine model) and compares them with experimental thermocouple data.

- **Convective & Radiative Heat Transfer ($h_c$, $h_r$)** calculated dynamically.
- **Experimental Data Validation**
- **Automated Plot Generation** for each power level.

## Requirements
- MATLAB R2020b or newer
